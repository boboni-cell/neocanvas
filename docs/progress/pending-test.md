# 待测试

本次改造需人工验证：

- 品牌：页面标题、顶部导航、登录页、后台侧边栏、默认项目名、导出文件名均已改为 NeoCanvas；Logo 使用品牌文字 + 荧光绿 N 图标。
- 主题：默认暗色主题为黑色底 + 荧光绿（#00ff66），Ant Design 主色与画布主题同步为荧光绿。
- 提示词库：前台导航、首页展示、/prompts 页面、画布侧栏提示词 tab、生图/视频工作台提示词库入口、后台「提示词管理」均已移除，访问 /prompts 返回 404。
- 技能库：/skills 已改为「我的技能」市场——自定义技能可创建 / 编辑 / 删除并持久化；「内置」分类按类型分组展示，包含 drama-skills 9 个短剧技能 + SD 2.5 视频提示词方法 + 短视频提示词路由 + Higgsfield 15 个风格技能，共 26 个，均可「试试看」一键跳转画布助手。
- 视频提示词生成：画布 Agent 已把 SD 2.5 五段式方法（sd-2-5-prompt）设为视频提示词的权威方法，命中视频提示词 / 视频生成 / Seedance / 即梦 / 运镜 / 摄影等意图时自动注入。
- 画布 Agent 已接入 drama-skills：当用户意图命中短剧 / 剧本 / 分镜 / 视频提示词 / 资产 / 审查等关键词时，运行时会按意图加载对应 SKILL.md 全文注入系统提示词（缓存 + 每次最多 3 个技能）。
- 技能已接入画布对话框：在助手面板选择任意内置技能后，会注入该技能的浓缩版提示词；自动路由同样优先使用浓缩版，避免每次加载完整 SKILL.md 消耗过多 token（浓缩版位于 `web/src/data/skill-briefs.ts`，完整内容仍保留在 `public/` 下可回退）。
- 首页：按黑色+荧光绿风格重做，包含品牌 Hero、创作输入框、快速入口与功能说明，并加入环境光晕漂浮、卡片悬浮、滚动入场等动效。
- 首页主标语已改为视频方向：「从一句话开始，生成整支视频」。
- 登录页副标题已移除；右上角 GitHub 图标已移除。
- API 设置：已改为「我的 API」管理界面——左侧按 文本 / 图片生成 / 视频生成 / 音频 四个 tab 展示已保存接口（含使用/删除/当前操作），右侧为编辑表单（显示名称、接口服务商、Base URL、API Key、模型名称、测试连接、保存并设为当前）。接口服务商预设包括 OpenAI / DeepSeek / Anthropic Claude / Google Gemini / xAI Grok / OpenRouter / 硅基流动 / 通义千问 DashScope / Moonshot Kimi / 智谱 GLM / MiniMax / Atlas Cloud（全模型）/ Nano-GPT / 火山 Ark / 火山方舟 Agent Plan（视频）/ KIE（可灵）/ MiMo / New API / 自定义。
